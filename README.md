# Portafolio de Computación Avanzada

Portafolio en Streamlit con las aplicaciones desarrolladas durante el semestre en el
curso de Computación Avanzada (I.U. Pascual Bravo). Basado en la plantilla del curso:
cada tarjeta tiene título, imagen, descripción y enlace a la app desplegada.

Las apps HTML de KNN (sesión 12) y PCA (sesión 14) se publican como páginas internas
(`pages/`).

Para actualizar un enlace o una tarjeta, edita la lista `APPS` en `Intro.py`; las
imágenes van en `img/`.

```bash
pip install -r requirements.txt
streamlit run Intro.py
```
